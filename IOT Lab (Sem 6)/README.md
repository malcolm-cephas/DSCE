# IOT Lab (Sem 6) – Arduino and ESP 32 Experiments



## Experiment List

| Exp No | File | Description |
|------|------|-------------|
| 1 | [Exp 1](Exp%201.ino) | Connect an LED to an ESP32 and create a program that switches the LED on for 1 second every 2 seconds.|
| 2 | [Exp 2](Exp%202.ino) | Measure the temperature, humidity and heat index using ESP32 development board and display the values on serial monitor |
| 3 | [Exp 3](Exp%203.ino) | Calculate the distance to an object with the help of an ultrasonic sensor and display it on serial monitor. |
| 4 | [Exp 4](Exp%204.ino) | Measure soil moisture value using ESP32 development board and display the sensor values on serial monitor |
| 5 | [Exp 5](Exp%205.ino) | Motion detection using IR sensor and turn on buzzer upon detection |
| 6 | [Exp 6](Exp%206.ino) | Measure BPM value using pulse sensor and display on serial monitor. |
| 7 | [Exp 7](Exp%207.ino) | Configure/Set your ESP32 development broad as an access point. |
| 8 | [Exp 8](Exp%208.ino) | Scan Wi-Fi networks and get Wi-Fi strength using ESP32 development board. |
| 9 | [Exp 9](Exp%209.ino) | Establish connection between IoT node and access point and display of local IP and gateway IP.|
| 10 | [Exp 10](Exp%2010.ino) | Design and implementation of HTTP based IoT web server to control the status of LED. |
| 11 | [Exp 11](Exp%2011.ino) | Design and implementation of HTTP based IoT web server to display sensor value. |
| 12 | [Exp 12](Exp%2012.ino) | Design and implementation of MQTT based controlling and monitoring using Ubidots MQTT server. |
